How to run

The site uses ES modules so it must be served via a local web server rather than opened directly from the file system. The easiest way is to open the project folder in VS Code and use the "Live Server" extension — right-click index.html and choose "Open with Live Server".

python3 -m http.server 8000
then visit http://localhost:8000
