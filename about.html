About ORBIS

A 3D Planetary Observatory · 2026

ORBIS is an interactive web based 3D application. It presents a small catalogue of astronomical bodies — Earth, Mars, Jupiter, and the Moon — each rendered in real time in the browser using WebGL.

Visitors can rotate, zoom, and inspect each model, toggle between solid and wireframe views, adjust lighting in real time, and switch between specimens via the catalogue panel. Clicking directly on a model gives it a brief spin burst as visual feedback.

How it was built

The application is built from plain HTML5, CSS3, and JavaScript. There is no build step and no framework — the entire site runs by opening index.html in a browser.

3D content is rendered with the Three.js library (r160), loaded via an ES module import map directly from a CDN. Models are authored in Blender and exported as glTF/GLB. The Three.js scene composites them with directional and ambient lighting, and uses an OrbitControls rig to handle camera rotation and zoom.

The catalogue

Each entry in the catalogue is described by a JavaScript object holding its name, descriptive metadata, telemetry data, rotation speed, and a path to its GLB file. Switching specimens disposes the previous model's GPU resources before loading the next, so memory usage stays predictable no matter how many times the user browses.

Design philosophy

The interface borrows from the visual language of scientific instruments and old astronomical catalogues — a serif display face, monospaced data readouts, a restrained palette, and corner crops on the viewing stage, rather than the saturated colour and neon glow that dominate "space" themed websites. The aim is to make the 3D content the loudest element on screen.

We are made of star stuff. We are a way for the cosmos to know itself.

Tested on

Verified to run on current versions of Chrome, Firefox, Safari, and Edge on desktop, and on mobile Safari and Chrome on Android. WebGL 2 support is required.
